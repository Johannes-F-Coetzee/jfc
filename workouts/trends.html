You can't read this site's workout data

Workout data is stored in the site owner's Google Form, and only people who can edit that form can view the trends. To track your own workouts, fork the code and set it up with your own Google Form:

  1. Fork the repository. Open the fork page and create a fork in your GitHub account.
  2. Turn on GitHub Pages. In your fork, open Settings → Pages and choose Deploy from a branch with the main branch and / (root) folder. Your site will be at https://<your-user>.github.io/<repo-name>/workouts/.
  3. Create your Google Form. At script.google.com, create a project, paste in workouts/setup/create-form.gs and run createWorkoutForm. It creates the form and a response spreadsheet, then prints a form: {...} block.
  4. Create a Google Cloud project. In the Google Cloud Console:
    • Enable the Google Forms API under APIs & Services → Library.
    • Set up the OAuth consent screen and add your Google account as a test user.
    • Under Credentials, create an OAuth client ID of type Web application. Add https://<your-user>.github.io and, for local testing, http://localhost and http://localhost:8000 as Authorized JavaScript origins.
  5. Update workouts/config.js. Set googleClientId to your client ID, replace the form block with the one printed in step 3, and optionally set allowedEmails.
  6. Add your routines. Edit workouts/routines.json, or use Export routine (JSON) on the Log page and commit the downloaded file.
  7. Commit and push. After GitHub Pages redeploys, sign in on your own site to log workouts and view your trends.

The full guide is in the repository's README.
