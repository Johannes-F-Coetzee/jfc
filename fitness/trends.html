Sign in with your Google account to see your workout and measurement trends.

You can't read this site's workout data

Workout data is stored in the site owner's Google Form, and only people who can edit that form can view the trends. To track your own workouts, fork the code and set it up with your own Google Form:

  1. Fork the repository. Open the fork page and create a fork in your GitHub account.
  2. Turn on GitHub Pages. In your fork, open Settings → Pages and choose Deploy from a branch with the main branch and / (root) folder. Your site will be at https://<your-user>.github.io/<repo-name>/fitness/.
  3. Create your Google Forms. At script.google.com, create a project, paste in fitness/setup/create-form.gs and run createWorkoutForm and createWorkoutConfigurationForm. Each creates a separate form and response spreadsheet, then prints a form: {...} or configurationForm: {...} block. Publish both forms and allow anonymous responses. Share edit access to the configuration form with every tracker user so they can load shared workouts.
  4. Create a Google Cloud project. In the Google Cloud Console:
    • Enable the Google Forms API under APIs & Services → Library.
    • Set up the OAuth consent screen and add your Google account as a test user.
    • Add the forms.body.readonly and forms.responses.readonly scopes.
    • Under Credentials, create an OAuth client ID of type Web application. Add https://<your-user>.github.io and, for local testing, http://localhost and http://localhost:8000 as Authorized JavaScript origins.
  5. Update fitness/config.js. Set googleClientId to your client ID, replace the form and configurationForm blocks with those printed in step 3, and optionally set allowedEmails.
  6. Save your routines. On the Log page, enter exercises and sets under a unique routine name and choose Routine actions → Save as routine. Shared routines saved by all users load automatically; Routine actions → Refresh routines reloads them, and Export routines (JSON) downloads them as a backup; no routines file needs to be committed.
  7. Commit and push. After GitHub Pages redeploys, sign in on your own site to log workouts and view your trends.

The full guide is in the repository's README.

Your trends will appear here

Once your data loads, you'll see:

  • Summary - workouts, sets, reps, training time and average difficulty
  • Routines - how often you did each routine, when you last did it, and difficulty change
  • Exercise trend - a chart of one exercise over time
  • Measurement trend - charts and history for body measurements and daily states
  • All measurements - latest values and changes for each recorded metric
  • All exercises - a table of every exercise in the period
