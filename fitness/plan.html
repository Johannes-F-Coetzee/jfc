Plan form setup required

Run createWorkoutPlanForm in fitness/setup/create-form.gs and paste its logged planForm block into fitness/config.js. Publish the form, allow anonymous responses, and give tracker users edit access for loading. Local planning and JSON export still work without this setup.

Plan details

Apply the plan details before adding routines. Cycle days are dated from the start date. Drafts are saved on this device for your signed-in account. Use Save plan to Google Forms to keep a named snapshot.

Saved snapshots appear in the Plan name menu. Selecting one replaces this device's current draft after confirmation. Snapshots cannot be overwritten; use a new name for changes.
